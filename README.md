# ESCALA-DE-RAMSAY-2.0
La Escala de Ramsay es una herramienta clínica subjetiva desarrollada en 1974 por Michael Ramsay para evaluar el grado de sedación en pacientes, especialmente en Unidades de Cuidados Intensivos (UCI) o procedimientos médicos y odontológicos. Su objetivo es evitar la falta o el exceso de medicación sedante.

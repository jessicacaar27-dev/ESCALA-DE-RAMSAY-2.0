# Escala de Sedación de Ramsay

Aplicación interactiva educativa para la valoración del nivel de sedación del paciente mediante la escala original de Ramsay.

## Abrir la aplicación

- Abrir el archivo `index.html` en un navegador para ver la herramienta interactiva.
- También puedes abrirlo desde un servidor local simple si prefieres usar un entorno de desarrollo web.

## Descripción

La escala de Ramsay permite valorar el nivel de sedación del paciente en contextos clínicos como UCI, cuidados postoperatorios y observación durante procedimientos. Esta herramienta presenta los seis niveles originales, su interpretación, una escala visual interactiva y contenido didáctico para reforzar su uso clínico.

## Importante

La escala debe usarse por personal sanitario capacitado y siempre integrarse con la monitorización clínica, la prescripción médica y el juicio profesional.
